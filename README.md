# Web 音乐播放器 快速上手（简版）

面向非开发人员的入门指南，帮助你快速使用本项目进行本地或云端音频播放。

## 功能概览
- 支持本地文件夹导入（浏览器授权目录）
- 支持 Dropbox / 阿里云 OSS / 腾讯云 COS 音源扫描
- 播放控制：播放/暂停、上一首/下一首、进度条、音量/静音
- 曲库管理与歌单：创建、重命名、删除、导入/导出、拖拽重排
- 元数据编辑与自动补全（MusicBrainz）
- 虚拟列表流畅浏览、大文件缓存提升体验

## 环境要求
- 现代浏览器（推荐 Chrome/Edge；本地文件夹导入需支持 File System Access API）
- 如需本地运行开发服务器：Node.js 18+，npm

## 本地运行
1. 安装依赖：
   ```bash
   npm install
   ```
2. 启动开发服务器：
   ```bash
   npm run dev
   ```
3. 浏览器访问：http://localhost:5173

## 构建与预览
1. 构建产物：
   ```bash
   npm run build
   ```
2. 本地预览：
   ```bash
   npm run preview
   ```

## 使用指南
### 导入本地音频
1. 左侧面板选择“本地”
2. 点击“导入本地文件夹”，在弹出的系统对话框中选择包含音乐文件的目录
3. 首次导入会解析元数据并缓存，列表生成后即可播放

### 导入云端音源
- Dropbox：在“Dropbox”页签填写 Access Token 与根路径；点击“扫描并导入”
- OSS：填写 region、bucket、endpoint（可选）、prefix（可选）、accessKeyId、accessKeySecret、stsToken；点击“扫描并导入”
- COS：填写 region、bucket（不含 appid）、appId（可选）、prefix（可选）、临时密钥与 sessionToken；点击“扫描并导入”

### 歌单管理
- 在右侧歌单面板创建歌单、重命名或删除
- 导入/导出为 JSON 文件
- 列表行支持拖拽以重排（选择某个歌单后）

### 播放控制
- 底部控制栏支持上一首/播放或暂停/下一首
- 进度条支持拖动定位，显示已缓冲时长与总时长
- 音量滑块与静音开关

### 元数据编辑
- 右侧“正在播放”面板可编辑标题、艺术家、专辑
- 点击“自动补全”将尝试通过 MusicBrainz 获取补充信息

## 常见问题
- 无法播放：请确保有用户点击操作后再播放；部分浏览器的自动播放策略会阻止播放
- 本地文件夹不可选：需使用支持 File System Access API 的浏览器（Chrome/Edge 等），并授权访问
- 云端读取失败：检查凭证是否有效、Bucket/Region 是否正确、临时密钥是否过期
- 解析失败或封面缺失：取决于文件内嵌标签与外部服务命中情况

## 安全与隐私
- 不要将密钥/令牌写入仓库。使用临时凭证（STS）或后端授权机制。
- 本地缓存使用浏览器 IndexedDB，仅保存在本机。
